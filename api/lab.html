How this lab selects a token
The lab applies a sign-aware repetition penalty to tokens in the visible context, then temperature, then Top-K or Top-P. Greedy ignores temperature and puts all selection probability on one token. Filtered tokens have zero selection probability; sampling is weighted, not uniform. Manual choices can deliberately override the filter.
The lab uses its own versioned sampler, bb8-lab-v1, with a rolling context window and no KV cache. It inspects actual model logits but does not promise identical output or speed to the older chat generator.
